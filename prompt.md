# Prompt Library

Use these prompts directly in the chatbot.

## General Chat

- Explain this topic simply: [topic]
- Give me a short summary of [topic].
- Compare [option A] and [option B].
- Help me brainstorm ideas for [goal].

## Coding

- Write Python code for [task].
- Debug this error and explain the fix: [error].
- Refactor this code for readability: [paste code].
- Explain this function line by line: [paste code].

## Learning

- Teach me [topic] like I am a beginner.
- Quiz me on [topic] with 5 questions.
- Create a study plan for [topic].
- Show me common mistakes in [topic].

## Writing

- Rewrite this text in a clearer tone: [text].
- Make this message more professional: [text].
- Turn these notes into a polished paragraph: [notes].

## Project-Specific Prompts

- How does this chatbot work?
- Add streaming responses to this chatbot.
- Save the conversation history to a file.
- Explain how conversation history is maintained in a list.

## Exit

- Type `exit` or `quit` inside the app to close it.
